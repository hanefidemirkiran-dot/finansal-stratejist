HAFTALIK RAPOR
Otomatik E-Posta Kurulumu

Her Pazartesi sabahı otomatik rapor almak için:

Make.com (Kodsuz, Ücretsiz):
1. make.com'a üye ol → Yeni Senaryo → Schedule (Pazartesi 09:00)
2. HTTP Request modülü → POST senin-site.vercel.app/api/claude
3. Gmail modülü → raporu e-postaya gönder
4. Aktif et — bitti!

🚀 Vercel Kurulum Rehberi — 30 Dakikada Biter
Bu uygulamayı kalıcı olarak kullanmak için 3 şeye ihtiyacın var:
GitHub hesabı (ücretsiz) + Vercel hesabı (ücretsiz) + Anthropic API anahtarı (~$5-10/ay)
1
GitHub Hesabı Aç
github.com'a git → Sign Up → E-posta + şifre gir → Hesabı onayla.
Giriş yaptıktan sonra sağ üstte + → New repository tıkla.
İsim: finansal-stratejist → Public seç → Create repository.
2
Dosyaları GitHub'a Yükle
Aşağıdaki İNDİR butonuyla proje dosyalarını indir.
GitHub'da açtığın sayfada "uploading an existing file" linkine tıkla.
İndirdiğin 3 dosyayı sürükle-bırak → Commit changes tıkla.
3
Vercel'e Deploy Et
vercel.com'a git → Sign up with GitHub.
Add New Project → finansal-stratejist → Import.
Hiçbir şeye dokunma → Deploy tıkla → 1-2 dakika bekle.
✅ Sana bir link verecek: finansal-stratejist.vercel.app
4
Anthropic API Anahtarı Al
console.anthropic.com'a git → Hesap aç.
Sol menü → API Keys → Create Key → Çıkan kodu kopyala (sk-ant-...).
⚠️ Bu kodu kimseyle paylaşma!
5
API Anahtarını Vercel'e Ekle (ÇOK ÖNEMLİ)
Vercel Dashboard → Projen → Settings → Environment Variables.
Name: ANTHROPIC_API_KEY
Value: (az önce kopyaladığın sk-ant-... kodu)
Save tıkla → Sonra Deployments → son deploy → Redeploy tıkla.
✅ Artık AI çalışıyor!
6
Portföyünü Gir ve Kullanmaya Başla
Sitenizi açın → Portföy sekmesi → Örnek verileri sil → Kendi hisselerini gir.
Sonra Stratejist sekmesine geç ve ilk soruyu sor. 🎉
